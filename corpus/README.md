# Fault corpus (declared prior work)

Scenario definitions live in scenarios.yaml. Each generated scenario yields:
  <scenario>/techsupport.tar.gz   capture from a fault-injected sonic-vs
  <scenario>/ground_truth.yaml    sealed: root cause, faulty stage, key evidence
Ground-truth files stay sealed until scoring. Corpus tarballs are captured on
community SONiC 202605 sonic-vs images before the hackathon window and are
declared as prior work at submission and on the final slide.
